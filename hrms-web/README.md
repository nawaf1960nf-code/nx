# منصّة إدارة الموارد البشرية — تطبيق الويب

لوحة تحكم متعددة الشركات (SaaS) لإدارة الموارد البشرية، تعمل كموقع وتطبيق
قابل للتثبيت (PWA). واجهة عربية كاملة (RTL) بتصميم مؤسسي.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
```

البناء للإنتاج: `npm run build && npm start`.

> بيئة تجريبية: البيانات تُحفظ محلياً في متصفّحك (localStorage) عبر Zustand،
> ولا تحتاج خادماً أو قاعدة بيانات لتجربة كل التدفقات.

## حسابات الدخول التجريبية

| البريد | الدور |
| ------ | ----- |
| `admin@system.sa` | مدير النظام (يدير الشركات المشتركة) |
| `sara@alfajr.sa` | موارد بشرية — شركة الفجر |
| `majed@noor.sa` | موارد بشرية — مؤسسة نور |

## التقنيات

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Zustand · framer-motion
· lucide-react · SheetJS (استيراد/تصدير إكسل) · PWA (Service Worker + Manifest).

## الوحدات

| الوحدة | الوصف |
| ------ | ----- |
| الشركات المشتركة (SaaS) | إضافة/تعليق/تفعيل الشركات، الباقات، دعوة مسؤول الشركة بإيميل |
| الموظفون | قائمة وبحث، ملف بالتبويبات (شخصي/وظيفي/أداء/مالي/نهاية الخدمة/سجل زمني) |
| الحضور والانصراف | تسجيل حضور/انصراف مع حساب التأخير آلياً |
| الإجازات | طلبات إجازة بأنواعها مع اعتماد/رفض |
| الطلبات | إجازة، استئذان، سلفة، عمل عن بُعد، مستندات — بنموذج ديناميكي وسير اعتماد |
| المستندات | وثائق الموظفين وتواريخ انتهائها مع تنبيهات قبل الانتهاء |
| الإعلانات | نشر باستهداف (الكل / إدارة / موظفين محددين) |
| الإشعارات | جرس بعدّاد + صفحة كاملة، تُولَّد آلياً عند الأحداث |
| تقييم الأداء | تقييم بمعايير متعددة (1-5) مع النتيجة النهائية |
| الرواتب | كشف شهري مع احتساب التأمينات (GOSI) وخصم السلف والخصومات آلياً |
| السلف والخصومات | منح سلف بأقساط وخصومات تنعكس على الرواتب |
| التقارير | تعداد الأقسام ومخصص نهاية الخدمة مع تصدير إكسل |
| استيراد البيانات | رفع عدة ملفات إكسل لتعبئة بيانات الموظفين مع التحقق |
| سجل النشاط | توثيق كل حركة مع إمكانية التراجع عن الإجراءات الخاطئة |

## نهاية الخدمة (نظام العمل السعودي)

تغطي الحاسبة جميع المواد: 84 (الأساس)، 85 (تخفيض الاستقالة)، 87 (الاستثناءات)،
81 (ترك العمل لخطأ صاحب العمل)، 80 (الحرمان)، و74 (اتفاق الطرفين).

## الأمان على مستوى الحقول

البيانات المالية والبنكية والرواتب لا تُعرض إطلاقاً لغير الموارد البشرية ومدير
النظام — التبويبات المالية لا تُبنى أصلاً في DOM لمن لا يملك الصلاحية.
